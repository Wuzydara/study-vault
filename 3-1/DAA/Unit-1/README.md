# Algorithm

An **algorithm** is a sequence of precise, step-by-step instructions or rules designed to solve a problem or accomplish a specific task. For an algorithm to be computational, these steps must be described precisely enough that a computer or computational device can run it.

## The Five Core Criteria of an Algorithm

To be considered a valid algorithm, a procedure must satisfy the following five criteria:

1. **Input:** It must receive zero or more externally supplied quantities.
2. **Output:** It must produce at least one output quantity.
3. **Definiteness:** Each instruction in the algorithm must be clear, unambiguous, and well-defined.
4. **Finiteness:** The algorithm must terminate after a finite number of steps or within a finite amount of time.
5. **Effectiveness:** Every instruction must be extremely basic and feasible to perform.

> Algorithms that are both definite and effective are also referred to as **computational procedures**.

---

## Algorithms vs. Programs

While an algorithm represents the abstract logic or method for solving a problem, a **program** is the concrete expression of that algorithm written in a specific programming language. 
In computer science, an algorithm is typically conceptualized from an initial state and is designed to terminate in a defined end-state.

## Historical Origins and Examples

- **Origin:** From the name of the 9th-century Persian mathematician **Abu Ja’far Mohammed ibn Musa al Khowarizmi** (c. 825 A.D.), who provided step-by-step rules for decimal arithmetic.

- **Euclid’s Algorithm:** Developed between 400 and 300 B.C. to find the greatest common divisor (gcd) of two positive integers.
  - considered as the first non-trivial algorithm ever devised.

- **Everyday Analogy:** A recipe for making a cup of tea acts as an everyday algorithm, though it lacks the absolute mathematical precision required for a computer to execute without further definition.
